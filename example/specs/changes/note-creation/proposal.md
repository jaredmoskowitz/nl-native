# Proposal: note-creation

## What
Users can create, view, and delete personal notes. Each note has a title and a body. Notes are private to the user who created them.

## Why
This is the core value of the app. Without notes, there is nothing to work with.

## Scope

**In scope:**
- Creating a note with a title and body
- Viewing a list of all notes, newest first
- Deleting a note
- Persisting notes across app restarts (server-side storage)

**Out of scope:**
- Editing a note after creation (future feature)
- Sharing notes with other users (future feature)
- Attachments, images, or rich text formatting (future feature)
- Search or filtering (future feature)

**Open questions:**
- None. Scope is clear.
